# Glossary

本文件用于记录 Agent Engineer 学习过程中的术语。

| Term | Meaning |
| --- | --- |
| Agent | 能够基于目标、上下文和工具进行多步决策与执行的 AI 应用形态 |
| Tool Calling | LLM 按结构化参数调用外部工具或函数的能力 |
| Agent Loop | Agent 在观察、计划、行动和反馈之间循环推进任务的执行机制 |
| RAG | Retrieval-Augmented Generation，检索增强生成 |
| Embedding | 将文本、图片或其他信息编码为向量表示的技术 |
| Retrieval | 从知识库、向量库或其他数据源中召回相关信息的过程 |
| Memory | Agent 在一次或多次任务中保留和使用状态的机制 |
| MCP | Model Context Protocol，用于连接模型、工具和外部上下文的协议 |
| Evaluation | 对 Agent 或 LLM 应用质量进行评估的方法和流程 |
| Observability | 对 Agent 运行过程进行日志、trace、指标和调试观测的能力 |
