# Daily Learning Review Prompt

请根据今天完整的学习过程形成：

1. `notes/weekXX/dayXX.md`
2. `docs/LEARNING_STATE.md` 应更新的内容
3. `docs/CAPABILITY_MATRIX.md` 的状态变化

注意：

- 不要因为今天接触过某个知识点就标记为掌握。
- 只有我能够解释并理解代码调用链、输入输出、职责边界和异常路径，才可以标记为“基本掌握”。
- 只有我能够独立设计、实现、排查问题并解释取舍，才可以标记为“可独立实现”。
- 如果今天没有足够证据判断能力等级，保持原状态并明确写出待验证内容。
- 不要自动开始下一 Day 或下一 TASK。
